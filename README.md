# Finora

Finora is a learning-first multi-agent personal finance assistant.

The project is designed to teach:

- Agentic AI
- API development
- Tool calling
- Multi-agent orchestration
- SQL databases
- Full-stack development

## Core Agents

- Expense Agent
- Savings Agent
- Budget Agent

## Tech Stack

- Python
- FastAPI
- SQLite
- React
- LLM APIs
- LangGraph later in development

## Current Stage

Stage 1: Building the core SQLite finance database.
